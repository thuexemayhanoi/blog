# Theme Search: Static QA and Release Boundary

2026-10-14 | Branch: `feature/premium-theme-search-2026-10-14`.

New **real** search page `/tim-kiem/`, exposed in shared header/mobile/footer navigation. `tim-kiem.html` has `robots: noindex,follow` and `sitemap: false` to avoid indexing thin site-search results; existing URLs and SEO unchanged.

**Architecture**: `assets/data/search-recent.json` is generated at Jekyll build from only the **300 most recent posts**. This capped JSON is downloaded *only when users search* on `/tim-kiem/`; not injected into shared layout, not sent on home/category/post requests. JS is vanilla, accent-insensitive Vietnamese normalization, filters titles and descriptions, ranks and shows up to 24 on-site results. DOM is generated with `createElement` / `textContent` (not `innerHTML`); index URLs validated to same-origin relative paths. No API, AI writer or plugin.

**Honest full-corpus limitation**: for old posts not present in latest 300, explicitly labeled external Google `site:blog.thuexemaynguyentu.com` search is offered; it can only search pages Google indexed. Do not claim this static GitHub Pages setup queries all 40,000 published posts on-site. This avoids loading 40,000 records to a phone and bounds page byte transfer.
